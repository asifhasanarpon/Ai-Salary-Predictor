Academic Defense & Documentation

Laboratory Methodology & Academic Defense

Comprehensive theoretical justifications fulfilling course evaluation criteria.

1. ColumnTransformer Preprocessing (Cell 27)

Evaluated 15 predictor variables. Continuous numerical features (years_experience, weekly_hours, ai_tools_hours_per_week, etc.) were standardized via StandardScaler (μ=0, σ=1). Categorical features were transformed using OneHotEncoder(handle_unknown='ignore'), expanding inputs into 66 dense features without synthetic ordinal bias.

2. Why HistGradientBoosting Regressor Won (R² = 0.8447)

HistGradientBoosting operates by discretizing continuous variables into 256 integer-valued bins, drastically accelerating split evaluation while fitting successive trees on pseudo-residuals. It captures deep non-linear interaction terms (e.g., senior roles in high-paying geographies with leadership responsibilities) with minimal overfitting, achieving the highest R² (0.8447) and lowest MAE ($15,184).

3. Linear Regression & Random Forest Performance

With One-Hot Encoding, Linear Regression achieved a remarkable R² = 0.8055, confirming strong linear sub-relationships once category collinearity was decoupled. Random Forest Regressor scored R² = 0.7779 (MAE = $18,401), providing robust bagging variance reduction but slightly trailing gradient boosting on fine residual calibration.

4. Production Readiness & Business ROI

The live web deployment serves as an end-to-end inference microservice with zero cold-start latency (<5ms client evaluation). Model output provides a tight ±$15,184 confidence band based on empirical Mean Absolute Error, empowering candidates and HR committees to make data-grounded salary determinations.
