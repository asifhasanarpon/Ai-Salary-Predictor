Methodology & Academic Justifications

Summary of data preprocessing, model selection, and practical takeaways for the lab report.

1. Data Preprocessing

The dataset includes 5,000 records across 16 raw features. We imputed continuous features using median values and encoded categoricals with Target and One-Hot encoding to preserve non-linear relationship patterns.

2. Model Selection Rationale

Random Forest achieved R² = 0.744, cutting MAE by 42.6% over linear regression. It succeeded because tech compensation follows non-linear step jumps (e.g., Lead/Director promotions) that linear models fail to capture.

3. Practical Takeaways

Feature importance ranks Seniority Level (34.2%), Experience (26.8%), and Location (18.4%) as the leading drivers. Weekly AI tooling hours also demonstrated a noticeable positive wage premium.
