Academic Defense & Documentation

Lab Report Methodology & Rubric Defense

Comprehensive theoretical justifications fulfilling course evaluation criteria.

1. Feature Engineering & Preprocessing

Evaluated 27 candidate features from the 5,000-record dataset. Categorical features (job_title, company_location, education_level) were transformed using robust Label Encoding. All continuous numerical variables were standardized via StandardScaler (μ=0, σ=1) to prevent high-magnitude features (e.g., weekly hours) from distorting distance-based algorithms.

2. Why Random Forest Won (R² = 0.744)

Tech compensation is fundamentally non-linear with severe interaction effects: a Senior Lead in the United States earns vastly more than the sum of "Senior" and "US" alone. Random Forest operates by constructing 100 decorrelated decision trees using bootstrap aggregating (bagging) and random feature subspace splitting, naturally capturing high-dimensional interactions without overfitting.

3. Why Linear & KNN Regressors Failed

Linear Regression assumes strict additive linearity ($y = X\beta + \epsilon$), resulting in severe underfitting (R² = 0.3476, MAE = $34.8k). K-Nearest Neighbors (k=5) suffered from the curse of dimensionality across 15 features (R² = 0.2989, MAE = $35.4k), where Euclidean distance metrics become equidistant and uninformative in high-dimensional hyperspace.

4. Production Readiness & Business ROI

The web deployment serves as an end-to-end inference microservice with zero cold-start latency (<5ms client evaluation). Model output provides a ±$19,991 confidence band based on empirical Mean Absolute Error, empowering engineering talent and HR compensation committees to make statistically grounded equity and salary decisions.
