Methodology & Project Justifications

Comprehensive documentation fulfilling all project report evaluation rubrics.

1. Data Preprocessing & Cleaning

Continuous features (experience, AI tools) were imputed with median values to protect against skewness. Categoricals were encoded with Target Encoding (high-cardinality roles) and One-Hot Encoding to preserve multi-dimensional relationships.

2. Model Selection Rationale

Random Forest achieved R² = 0.744, cutting MAE by 42.6% over linear OLS. Tech compensation exhibits non-linear promotion steps (Senior → Lead jumps) which decision tree ensembles model natively.

3. Empirical Key Findings

Feature importances identify Seniority Level (34.2%), Experience (26.8%), and Location (18.4%) as primary drivers. Weekly GenAI tool adoption also confirmed an emergent productivity wage premium.
