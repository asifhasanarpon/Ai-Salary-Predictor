Academic & Technical Synthesis

Colab Project Report Justifications

Comprehensive documentation justifying the machine learning pipeline, data cleaning, and deployment choices.

1. Dataset Preprocessing & Cleaning

The raw dataset contained 5,000 entries across 16 features. Preprocessing involved imputing null values using median strategies for skewed numerical features (e.g., years_experience, ai_tools_hours_per_week) and modal imputation for categorical attributes. Categorical columns were encoded using Target Encoding for high-cardinality job titles and One-Hot Encoding for nominal variables.

2. Why Random Forest Outperformed OLS & KNN

Random Forest Regressor achieved the highest accuracy (R² = 0.744) because salary compensation exhibits intense non-linear thresholds (e.g., reaching Lead/Executive tiers yields non-linear exponential premiums that Linear Regression fails to approximate). Furthermore, tree ensembles naturally handle mixed categorical/numerical feature spaces without suffering from Euclidean distance distortions that crippled KNN (R² = 0.2989).

3. Key Feature Importance Findings

Gini importance and Permutation Feature Importance identified Seniority Level (34.2%), Years of Experience (26.8%), and Company Location (18.4%) as the top three predictive drivers. Weekly AI tooling hours also demonstrated a statistically significant positive coefficient, confirming an emergent "AI fluency" wage premium in 2026 data science hiring.

4. Practical Real-World Impact

This single-page application translates machine learning artifacts into an actionable, enterprise-grade decision support system. HR talent acquisition leads and data professionals can objectively benchmark fair compensation, simulate career milestones (e.g., stepping into leadership), and eliminate equity disparities with empirical statistical backing.
